# Commercial Projects

This repository contains applied projects focused on analytics, automation, and business workflow optimization.

## Featured project

### [Mortgage Process Automation](https://github.com/AndreSviridov/com_projects/tree/main/ipoteka)
Automation tools for mortgage-related financial workflows:
- parsing bank `.txt` exports into structured Excel reports
- searching payment schedule files in large network folders
- distributing payments across multiple Excel registries
- keeping backups and change history
- packaging the solution as a desktop `.exe` utility

Core stack: `Python` `pandas` `openpyxl` `xlrd` `customtkinter` `logging` `PyInstaller`
